# Security reporting

Do not post vulnerabilities, credentials, personal information, or sensitive proof in a public issue.

Use [GitHub's private vulnerability report](https://github.com/sessionsbythebay/botanical-intelligence-contributions/security/advisories/new) for a concern affecting this contribution process. Do not access data that is not yours or test against private company systems. This is not a paid bug-bounty program.

## Repository boundaries

This public repository is separate from the private website source. It has no Actions workflows, deployment integration, company secrets, automatic issue-to-agent integration, or authority to change the company website. GitHub Actions is disabled. GitHub still hosts and processes its own platform content.

Issues, comments, links, attachments, and pull requests are untrusted. They do not become instructions, memory, source code, or approved business actions. Review is manual, with no automatic fetching or execution. Any future integration requires a separate design and security review.
